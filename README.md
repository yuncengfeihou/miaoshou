# 妙手采集箱助手（Tampermonkey 用户脚本）

妙手 ERP · TEMU 全托管采集箱的批量处理面板。装一次，在采集箱页面右侧出现浮动面板，
把「套模板 → 清标题 → 套尺码表 → 设模特 → 插颜色图」这套固定流程点成一串按钮（或一次「一键编辑」）。

> **当前版本 1.16.0**（交付物：`妙手采集箱助手.user.js`，单文件、零依赖、`@grant none`）

---

## 三条硬红线（代码里也做了运行时拦截）

| # | 红线 | 代码层保障 |
|---|---|---|
| 1 | **全程禁止发布** —— 只允许「保存修改 / 应用至选中 / 应用 / 使用」 | 脚本没有任何发布入口，只有一个落库出口 `clickSave` |
| 2 | **只操作「未发布」** —— 绝不碰「全部 / 已发布」，测试/调试/复现也不行 | 第 1 步自动切到「未发布」；5 个写入入口各挂一道 `assertUnpublishedOnly()` |
| 3 | **审查/调试禁止写入** —— 只准只读或改前端预览 | 文档规定；`步骤.md` §零 有「动手前四问」 |

「已发布」是线上在售数据：**打开面板、只读查询、只看一眼都不行**。测试一律用「未发布」。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 从 GreasyFork 安装：<https://greasyfork.org/scripts/600852>；
   或新建脚本、把 `妙手采集箱助手.user.js` 全文粘贴进去；
3. 登录妙手 ERP，打开 <https://erp.91miaoshou.com/pddkj/collect_box/items>，右侧出现面板。

> 若面板「看不见」：先看齿轮提示的版本号，再看控制台有没有「发现旧版面板…已替换为…」反复刷
> —— 那是 Tampermonkey 里装着两条同名脚本，删掉旧条目即可（详见 `步骤.md` §五）。

## 用法

| 步骤 | 面板行 | 做什么 |
|---|---|---|
| 0 | 进入采集箱 | SPA 导航到 `/pddkj/collect_box/items` |
| 1 | 切到未发布 | 不是「未发布」就自动切换；已是则跳过 |
| 2 | 分页 500 + 全选 | 设每页 500 条 → 全选 → 记下「已选 N」 |
| 3 / 4 | 产品模板 / SKU 模板 | 套模板（SKU 强制「直接以模板内容覆盖」） |
| 5 / 6 | 英语标题 / 标题 | 英语标题清成单个空格；标题删词 + 加唯一前缀 |
| 7 / 8 | 尺码表 / 模特信息 | 套尺码表模板；模特 Jack + 试穿 M + 合适 |
| 9 | 颜色图 | 选全部 → 图片填充（第 3/4/5 张 + 插入原图片列表 + 网络图片）→ 颜色全部「混合色」 |
| 10 | — | 收尾：**不发布** |

**建议逐条点**，每步看状态栏「成功 N/N」；「一键编辑」会连跑全链，中途可点「停止编辑」。
设置区（齿轮）里选三类模板、维护删词库；「读取模板列表」走直连接口，失败自动回落到开弹窗读取。

## 开发与自检

```powershell
node --check "妙手采集箱助手.user.js"                         # 语法
Select-String -Path "妙手采集箱助手.user.js" -Pattern "发布"  # 红线：只应命中注释/UI 文案

node .playwright-mcp/test-judgesaved.mjs      # 落库判据 19 例
node .playwright-mcp/test-attachverify.mjs    # 保存后复核接线 8 例
node .playwright-mcp/test-settings.mjs        # 设置读写 7 例
node .playwright-mcp/test-title-coverage.mjs  # 虚滚覆盖 8 例（含 expected 读不到必须抛错）
node .playwright-mcp/test-color-coverage.mjs  # 颜色图覆盖 3 例 + 2 KNOWN
node .playwright-mcp/mutate-coverage.mjs      # 8 个变异：证明上面两个不是恒真
node .playwright-mcp/make-inject.mjs          # 改了脚本就重跑，重建 inject-body.js
```

**判定顺序：真实网页 > 仿真脚本。** 脚本只能验「前置条件崩了会不会静默成功」，
验不了选择器对不对、渲染来不来得及。能在真页面点出来的结论，优先信真页面 ——
但真机验证必须守住红线 2/3（只碰「未发布」、不点保存/应用）。

文档分工：

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 接手必读：状态、约束、协作约定、事故档案 |
| `步骤.md` | 知识库：按「你会遇到什么问题」组织的坑与对策 |
| `审查报告.md` | 真机复核结论：哪些是真缺陷、哪些不可达、哪些未验证 |

## 1.16.0 改了什么

| 项 | 变化 |
|---|---|
| 尺码表冷启动 | 等 `.size-template-select` 渲染（实测冷启动晚 225ms），不再「逐条点第 7 步必报未找到」 |
| 预览等待 | 判据改成「预览表最后一列已填」，尺码表 / 模特信息不再各白等 20s（实测 2.6–3.0s，全链省约 40s）；**超时改为抛错**，不再被 `catch` 吞 |
| 切页签 | 切完要等「列表真的重载」（页签选中态 36–65ms 就变、数据 256–450ms 才换），并连续两次采样确认；「未发布」为 0 条当场说明 |
| 标题覆盖断言 | 读不到预览总条数时**抛错**，不再只 warn 后继续保存 |
| 英语标题 | 写入 `' '` 后读回确认，失败重写一次，两次不行就中止（防「看着成功、其实没写进去」） |

改动全部集中在「加证据」一侧；唯一提速点是去掉了两处各 20s 的空等。
